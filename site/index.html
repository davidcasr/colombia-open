colombia-open

Datos públicos de Colombia, listos para usar en Python.

Cada fuente oficial empieza dispersa, en su propio formato. La curamos, la normalizamos, la validamos — y la distribuimos como un dataset limpio, con su fuente y licencia siempre visibles.

Ver catálogo Ver en GitHub

Así se usa

Sin cuentas, sin tokens, sin lidiar con el portal del DANE.

$ pip install colombia-open

from colombia_open import ColombiaOpen

hub = ColombiaOpen()
municipios = hub.load_polars("municipios")
municipios.filter(municipios["cod_dpto"] == "05")  # municipios de Antioquia

hub.resolve_municipios(["Medellín", "cali", "BOGOTA"])
# resuelve nombres a código DIVIPOLA

Fuente: DANE — DIVIPOLA, vía datos.gov.co
