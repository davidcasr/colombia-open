colombia-open

Datos públicos de Colombia, listos para usar en Python.

Cada fuente oficial empieza dispersa, en su propio formato. La curamos, la normalizamos, la validamos — y la distribuimos como un dataset limpio, con su fuente y licencia siempre visibles.

Ver catálogo Ver en GitHub

Así se usa

Sin cuentas, sin tokens, sin lidiar con decenas de portales distintos.

$ pip install colombia-open

from colombia_open import ColombiaOpen

hub = ColombiaOpen()
municipios = hub.load_polars("municipios")
municipios.filter(municipios["cod_dpto"] == "05")  # municipios de Antioquia

hub.resolve_municipios(["Medellín", "cali", "BOGOTA"])
# resuelve nombres a código DIVIPOLA

Catálogo

Lo que hay disponible hoy. Crece una fuente a la vez — ver el roadmap completo abajo.

Departamentos

departamentos

Departamentos de Colombia: código DIVIPOLA de 2 dígitos y nombre oficial.

33 filas parquet · json CC BY-SA 4.0

Fuente: DANE — DIVIPOLA, vía datos.gov.co

Municipios

municipios

Municipios de Colombia: código DIVIPOLA de 5 dígitos, nombre, departamento y centroide (lon/lat). Geometría de polígonos en un dataset aparte.

1,122 filas parquet · json CC BY-SA 4.0

Fuente: DANE — DIVIPOLA, vía datos.gov.co

Municipios geometría

municipios_geometria

Geometría de polígonos municipales (Marco Geoestadístico Nacional), simplificada, con área geodésica.

1,122 filas parquet · json CC BY-IGO 3.0

Fuente: DANE (MGN), vía HDX — Colombia Subnational Administrative Boundaries

Demografía

demografia

Proyecciones de población municipal por área geográfica (cabecera, centros poblados y rural disperso, total), años 2018-2042.

84,225 filas parquet · json Términos DANE

Fuente: DANE — Proyecciones de Población (PPED)

Educación establecimientos

educacion_establecimientos

Directorio único de establecimientos educativos de Colombia (preescolar, básica y media), años 2015-2025.

606,206 filas parquet · json CC BY-SA 4.0

Fuente: MEN — Directorio de establecimientos, vía datos.gov.co

Delincuencia hurto personas

delincuencia_hurto_personas

Víctimas de hurto a personas por municipio y día, desde 2003 hasta el último corte mensual de la fuente.

650,835 filas parquet · json CC BY-SA 4.0

Fuente: MinDefensa / Policía Nacional — Hurto a personas, vía datos.gov.co

Delincuencia lesiones personales

delincuencia_lesiones_personales

Víctimas de lesiones personales y en accidente de tránsito por municipio y día, con conducta, arma, género y grupo etario, desde 2010.

1,377,323 filas parquet · json CC BY-SA 4.0

Fuente: Policía Nacional — Lesiones personales y en accidente de tránsito, vía datos.gov.co

Delincuencia hurto modalidades

delincuencia_hurto_modalidades

Víctimas de hurto a residencias y entidades comerciales por municipio y día, con arma, género y grupo etario, desde 2010.

397,361 filas parquet · json CC BY-SA 4.0

Fuente: Policía Nacional — Hurto por modalidades, vía datos.gov.co
